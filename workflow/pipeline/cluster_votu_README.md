# Кластеризация в vOTU (`cluster_votu.py`, `catalog_subsets.py`)

**Вход.** 119 последовательностей `strict_ge5kb.fna` и таблица BLASTN «все против всех» (14 колонок, включая `nident` и `btop`; команда — `06_cluster_votu.sh`).

**Сходство пары.** Участки выравнивания (HSP) обрабатываются по убыванию bitscore; позиции, уже выровненные в любой из двух последовательностей, повторно не учитываются. Две взаимные ориентации рассматриваются отдельно. Идентичность — доля совпадающих колонок среди оставленных, включая разрывы; покрытие — доля уникальных выровненных позиций более короткой последовательности. Пара проходит порог при идентичности ≥95 % и покрытии ≥85 % хотя бы в одной ориентации.

**Кластеры.** Представители выбираются по убыванию длины, при равенстве — по идентификатору. К представителю присоединяются ещё не распределённые последовательности, проходящие порог с ним; транзитивного объединения нет. Итог — 97 кластеров (80 одиночных, 17 многокомпонентных); между разными кластерами пар, проходящих порог, нет. Четыре кластера (vOTU_005, 006, 008, 012) не являются полными кликами: часть коротких членов проходит порог только относительно представителя.

**Выход.**

| Файл | Содержимое |
|---|---|
| `representatives_ge5kb.fna` | 97 представителей — каталог vOTU |
| `representatives_ge10kb.fna` | 41 представитель длиной ≥10 000 б |
| `clusters.tsv` | состав кластеров и число членов по образцам |
| `membership.tsv` | все 119 последовательностей, их представители и метрики сходства |
| `pairwise_metrics.tsv` | метрики всех пар с совпадениями BLAST |
| `assembly_presence_ge5000.tsv`, `assembly_presence_ge10000.tsv` | присутствие vOTU в сборках по членам кластера ≥5 и ≥10 кб |
