# Отбор вирусных кандидатов (`filter_candidates.py`)

**Вход.** Для каждого фагома — `final-viral-score.tsv` VirSorter2 и выходы `checkv end_to_end` (`quality_summary.tsv`, `contamination.tsv`, `viruses.fna`, `proviruses.fna`); всего 1162 кандидата.

**Последовательности.** Используются готовые `viruses.fna` и `proviruses.fna` CheckV: у провирусов взяты вирусные участки после удаления хозяйских краёв. Идентификатор дополняется префиксом образца (`MV-4122_S12__NODE_…`), чтобы имена контигов разных сборок не совпадали. Оценки качества, score и числа генов в таблицах относятся к кандидату до обрезки.

**Правила, по порядку применения.**

1. Четыре кандидата с совпадениями с рибосомными белками, без вирусных генов CheckV и с хозяйскими генами (MV-4122: NODE_2365, NODE_3558; MV-4125: NODE_1759; MV-4128: NODE_726) — `exclude_strict`.
2. Вирусных генов CheckV нет, хозяйские есть — `exclude_strict`.
3. Нет ни вирусных, ни хозяйских генов — `review`.
4. Есть вирусные гены, но CheckV выдал предупреждение — `review`.
5. Есть вирусные гены, предупреждений нет и выполнено одно из условий: score VirSorter2 ≥0,9; score ≥0,7 и хотя бы один hallmark-ген; категория CheckV Complete или High-quality — `strict_supported`.
6. Остальные — `review`.

**Выход.**

| Файл | Содержимое |
|---|---|
| `candidate_decisions.tsv` | все 1162 кандидата: решение, причина, исходные показатели |
| `sequence_manifest.tsv` | связь выходного идентификатора с кандидатом, длина после обрезки, координаты во входе CheckV |
| `summary.tsv` | сводка по образцам |
| `all_after_checkv.fna` | все 1162 последовательности после обрезки |
| `strict_supported.fna` | 294 кандидата, прошедшие правило 5 |
| `strict_ge5kb.fna` | 119 из них длиной ≥5000 б — вход кластеризации |
| `strict_ge10kb.fna` | 51 из них длиной ≥10 000 б |
| `short_HQ.fna` | Complete и High-quality короче 5000 б (в этих данных пуст) |
| `review.fna`, `exclude_strict.fna` | 389 и 479 кандидатов |
| `input_sha256.txt` | контрольные суммы входных файлов |
