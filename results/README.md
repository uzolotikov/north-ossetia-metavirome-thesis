## Получено отдельным разбором

Эти файлы не пишет ни один скрипт `workflow/`. Они получены отдельными командами по ходу анализа и сохранены,
чтобы утверждения тезиса можно было проверить.

- `contamination/nc1_megahit.log` — сборка отрицательного контроля NC1 программой MEGAHIT 1.2.9 из окружения
  `mvtools`. Из 103 764 очищенных прочтений не собрано ни одного контига.
- `contamination/rp_hits_MV4128.tsv` — гены рибосомных белков в сборке MV-4128: белок и профиль Pfam.
- `contamination/top8_MV4128.tsv` — восемь контигов MV-4128 с наибольшим произведением длины на покрытие:
  длина, покрытие по SPAdes и их произведение.
- `contamination/top_rp.faa`, `top_rp_remote.tsv` — рибосомные белки самых обильных контигов MV-4128 и ответ
  удалённого BLASTP по NCBI nr (02.10.2026): ближайшие последовательности принадлежат *Sphingomonas*.
- `hosts/phist_strong_hosts.fna`, `phist_strong_hosts_nt.tsv` — контиги-хозяева сильных предсказаний PHIST и
  ответ удалённого BLASTN по NCBI nt (02.10.2026), например *Brevundimonas* для `cell-4125-0-44_S16__NODE_13`.
- `hosts/remote_blast/` — то же для отдельных контигов-хозяев: запрос `.fna` и ответ `.tsv`.
- `hosts/crispr/spacers_cell_vs_votu.hits.tsv`, `spacers_cell_vs_votu.relaxed.tsv` — поиск в каталоге vOTU только
  спейсеров клеточных сборок, со строгим и ослабленным порогом. Обе таблицы пусты: спейсеры клеточных сборок
  ни на одну vOTU не попадают.

## Чем отличаются два порога «следует за контаминантом»

В `tables/votu97_catalog_flags.tsv` столбец `follows_contaminant` считается по окну «в пределах 1,5 раза» от
отношения обилий контаминанта Тиб-2 / Бирагзанг (0,544), то есть 0,363–0,817. Категория `3_follows_sph` в
`tables/votu_origin.tsv` использует другой диапазон, 0,339–0,693: в нём лежат отношения 18 из 24 vOTU, общих для
Тиб-2 и Бирагзанга, а остальные шесть разбросаны от 0,817 до 10,09. Граница окна в 1,5 раза проходит ровно по
vOTU_018 (0,8173), и результат по нему зависел бы от третьего знака оценки, поэтому в тезисе используется
диапазон. Обоснование записано и в шапке `workflow/analysis/13_virus_origin.py`.
