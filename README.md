# Фагом минеральных источников Северной Осетии: преобладание неизвестных бактериофагов

Код и данные для повторения анализа из тезиса:

> Синявский Н.Н., Золотиков У.Е., Тощаков С.В. Фагом минеральных источников Северной Осетии: преобладание
> неизвестных бактериофагов // Курчатовский геномный форум. Москва, 2026.

НИЦ «Курчатовский институт», Москва. Контакт: nekitsinyavskiy@gmail.com

## Что проверялось

Вирусы подземных вод изучены плохо: в таких водах мало биомассы и ещё меньше вирусной ДНК. Работа описывает
фракцию вирусных частиц трёх минеральных источников Северной Осетии, отобранных в 2020 г.:
- Тиб-1 и Тиб-2 — холодные выходы системы Тиб, 15,5 и 16,8 °C;
- Бирагзанг — термальный щелочной источник, 48 °C, pH 8,8.

Все найденные во фракции вирусы — бактериофаги, поэтому она называется фагомом. Клеточные фракции тех же
точек, цельная вода Бирагзанга и отрицательный контроль отсеквенированы в том же запуске, и по ним проверяется,
откуда взялся каждый фаг.

Результат кратко:
- Каталог из 97 vOTU длиной от 5 тыс. п. н.; 88 из них — вирусы по geNomad: 87 хвостатых фагов
  (*Caudoviricetes*) и один нитчатый (*Inoviridae*).
- Почти все фаги неизвестны. Средняя идентичность аминокислотных последовательностей (AAI) с ближайшим
  геномом базы CheckV 24–76 %, медиана 46 %; у 85 из 88 ниже 70 %. До семейства отнесены три фага.
- Около трети фагов умеренные: 15 найдены встроенными в бактериальные контиги, ещё у 13 есть гены лизогении.
- Во фракции вирусных частиц много бактериальной ДНК, которой нет в остальных библиотеках прогона;
  преобладает *Sphingomonas*. Не менее 27 из 88 фагов связаны с этой ДНК. Клеточными фракциями своих точек
  подтверждены 15 фагов.

## Установка

```bash
for f in envs/*.yml; do mamba env create -f "$f"; done
```

Окружения разделены по программам так же, как в работе. Для всех окружений, кроме `fastp` и `barrnap-env`,

## Запуск

```bash
cp config.example.sh config.sh       # указать пути и число потоков
bash workflow/run_all.sh
```

`run_all.sh` выполняет шаги по порядку. Их можно запускать и по одному, например
`bash workflow/pipeline/03_virsorter2.sh`. Для конвейера нужно около 80 ГБ в рабочем каталоге.

| Шаг | Что делает |
|---|---|
| `01_fastp.sh` | Тримминг 11 библиотек |
| `02_metaspades.sh` | Сборка трёх фагомов и четырёх клеточных фракций Тиб |
| `03_virsorter2.sh`, `04_checkv.sh` | Поиск вирусных контигов, качество и обрезка провирусных краёв |
| `05_filter_candidates.sh` | Отбор вирусных кандидатов |
| `06_cluster_votu.sh` | Кластеризация в vOTU |
| `07_map_catalog.sh`, `08_votu_coverage.sh` | Картирование 11 библиотек на каталог, таблицы покрытия |
| `09_markers.sh` | Гены 16S рРНК и рибосомные белки в сборках фагомов |
| `10_blast_references.sh` | Сравнение каталога с бактериальными сборками тех же точек |
| `analysis/00_*`–`09_*` | Сборка без `--meta`, MV-специфичная ДНК в прогоне, общий референс, geNomad, профаги, CRISPR, PHIST |
| `analysis/10_*`–`14_*` | Итоговые таблицы: подтверждение клетками, каталог с пометками, покрытие, происхождение, новизна |

Параметры каждого шага — в [docs/pipeline.md](docs/pipeline.md).

`tests/check_reproducibility.sh` пересчитывает шаги, не требующие сборки и картирования, и побайтно сверяет
47 файлов с рабочим каталогом.

### Методика

- **Кандидаты.** Контиги VirSorter2 (score ≥ 0,5, ≥ 1500 п. н.) после обрезки провирусных краёв CheckV.
  Кандидат проходит, если у него есть вирусные гены CheckV, нет предупреждений и выполнено одно из условий:
  score ≥ 0,9; score ≥ 0,7 и хотя бы один hallmark-ген; качество CheckV Complete или High-quality.
- **vOTU.** Кандидаты ≥ 5 тыс. п. н. объединяются при идентичности ≥ 95 % и покрытии более короткого ≥ 85 %;
  представители выбираются по убыванию длины, без транзитивного объединения. Подробно — в
  [cluster_votu_README.md](workflow/pipeline/cluster_votu_README.md).
- **Детекция.** vOTU найдена в библиотеке, если ширина покрытия ≥ 75 % и средняя глубина ≥ 1×.
  Прочтения: MAPQ ≥ 20, первичные выравнивания, не более 5 % несовпадений.
- **MV-специфичная ДНК.** Контиги общего референса, нормированная глубина которых в фагомах не меньше чем
  в 100 раз выше, чем в клеточных библиотеках. Их нет и в остальных библиотеках прогона.
- **Подтверждение клетками.** RPM vOTU в клеточной фракции своей точки не меньше 0,1 от RPM в фагоме
  при ≥ 10 прочтениях. Фон просачивания MV-специфичной ДНК в клеточные библиотеки — 5·10⁻⁴.
- **Происхождение.** Фаг связан с MV-специфичной ДНК, если встроен в её контиг, служит мишенью её спейсеров
  CRISPR или его отношение обилий Тиб-2 / Бирагзанг лежит в диапазоне контаминанта 0,339–0,693.
- **Новизна.** AAI с ближайшим геномом базы CheckV.

## Результаты

Конвейер пишет итоговые таблицы в `out/analysis/report`. Их копии, полученные на данных работы, лежат в
`results/tables/`; что лежит в остальных каталогах `results/`, описано в [results/README.md](results/README.md).

| Вопрос | Файл |
|---|---|
| Какие фаги найдены, их таксономия и рекомендация по каждому | `results/tables/votu97_catalog_flags.tsv` |
| Связан ли фаг с MV-специфичной бактериальной ДНК | `results/tables/votu_origin.tsv` |
| Насколько фаги новые, гены лизогении | `results/tables/votu_novelty_lysogeny.tsv` |
| Покрытие каждой vOTU в каждой библиотеке | `results/mapping/votu97_all_libraries.tsv`, `results/tables/votu_coverage_matrix.tsv` |
| Подтверждение клеточной фракцией | `results/tables/votu_confirmed_cellular.tsv` |
| Доля MV-специфичной ДНК в библиотеках | `results/tables/step6_read_fractions.tsv`, `results/contamination/runwide_presence.tsv` |
| Чистота фракции: 16S, рибосомные белки | `results/tables/purity_table.tsv` |

| Фагом | Пар прочтений после тримминга, млн | На вирусных контигах | MV-специфичная бактериальная ДНК | vOTU найдено | Доля прочтений каталога у фагов, связанных с MV-специфичной ДНК |
|---|---|---|---|---|---|
| Тиб-1 | 19,0 | 0,49 % | 78,0 % | 73 | 67 % |
| Тиб-2 | 12,8 | 0,85 % | 73,5 % | 55 | 92 % |
| Бирагзанг | 20,3 | 1,19 % | 71,0 % | 37 | 99 % |

Число найденных vOTU дано по всем 97 vOTU при ширине покрытия ≥ 75 %. Из 15 фагов, подтверждённых клетками,
14 подтверждены в Тиб-2 и один в Бирагзанге.

**Качество библиотек.** При тримминге отбрасывается 30–87 % прочтений, почти целиком как более короткие, чем
75 б, — обычное дело для библиотек с малым количеством исходной ДНК. Сильнее всего это затрагивает клеточные
фракции 0,22 мкм, Бирагзанг и отрицательный контроль (`results/qc/fastp/`).

## Ограничения

- Каждая точка представлена одной пробой без повторностей.
- Фагомы разных источников между собой не сравниваются: распределение фагов по точкам отражает прежде всего
  распределение MV-специфичной бактериальной ДНК.
- Откуда взялась MV-специфичная ДНК, не установлено. *Sphingomonas* — обычный контаминант работ с малой
  биомассой; в фагомах Тиб-2 и Бирагзанга, точек в 35 км друг от друга, он идентичен на 99,94 %
  (`results/tables/contaminant_ani.tsv`).
- Цельная вода отсеквенирована только для Бирагзанга.
- Хозяева фагов предсказаны: по встройке профага, по общим k-мерам (PHIST) и спейсерам CRISPR. Экспериментально
  они не проверялись.
- Секвенировалась только ДНК; РНК-вирусы в работу не входят.
