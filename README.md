# Фаги минеральных источников Северной Осетии

Метагеномное исследование фракции вирусных частиц (фагома) трёх минеральных источников Северной Осетии — двух холодных выходов системы Тиб (Тиб-1 и Тиб-2; 15,5 и 16,8 °C) и термального щелочного источника Бирагзанг (48 °C, pH 8,8) — с клеточными фракциями и цельной водой тех же точек. Отбор проб — 2020 г.

**Авторы:** Н. Н. Синявский, У. Е. Золотиков, С. В. Тощаков (НИЦ «Курчатовский институт»).

## Основные результаты

- **Каталог из 97 vOTU** (≥5 кб), из них 88 — вирусы по geNomad: 87 хвостатых фагов (*Caudoviricetes*) и один нитчатый (*Inoviridae*). Почти все неизвестны: средняя идентичность аминокислотных последовательностей с ближайшим геномом базы CheckV 24–76 % (медиана 46 %), до семейства отнесены только три.
- **Фракция вирусных частиц содержит много бактериальной ДНК.** На вирусные контиги приходится 0,5–1,2 % прочтений фагомов; 71–78 % — бактериальная ДНК, которой нет в клеточных фракциях, цельной воде и остальных библиотеках прогона. Доминирует *Sphingomonas*, идентичный в двух фагомах на 99,94 %. Не менее 27 из 88 фагов связаны с этой ДНК, и по обилию они составляют 66–98 % прочтений каталога.
- **Пятнадцать фагов подтверждены клеточными фракциями своих точек.** Состав фагомов разных источников между собой не сравнивается: сходство отражает распределение MV-специфичной бактериальной ДНК.

## Данные

Одиннадцать библиотек из прогона Illumina NovaSeq HY5G3DRXX (проект Ossetia-2020, 56 библиотек, парные прочтения 151 б): три фагома, шесть клеточных фракций, цельная вода Бирагзанга и отрицательный контроль.

| Тип | Библиотеки |
|---|---|
| Фагом (Sterivex 0,22 мкм → Amicon 30 кДа) | MV-4122_S12 (Тиб-1), MV-4125_S18 (Тиб-2), MV-4128_S29 (Бирагзанг) |
| Клетки, фильтры 0,44 / 0,22 мкм | 4122-0-44_S10, 4122-0-22_S11, 4125-0-44_S16, 4125-0-22_S17, 4128-0-44_S27, 4128-0-22_S28 |
| Цельная вода | 4128_S30 |
| Отрицательный контроль | NC1_S64 |

- `metadata/libraries.tsv` — библиотеки: точка, фракция, файлы, md5, размеры, число пар прочтений до и после тримминга.
- `metadata/sites.tsv` — точки отбора: исходные идентификаторы образцов, координаты, температура, pH, Eh.
- `metadata/mv_ossetia_manifest.tsv` — пути к исходным файлам прогона.

**Сырые прочтения** (20 ГБ) хранятся на сервере labg в `/mss5/Reads/Metagenome/Ossetia-2020/`; публикация в NCBI SRA планируется.

**Качество библиотек.** При тримминге отбрасывается 30–87 % прочтений, почти целиком как более короткие, чем 75 б, — типично для библиотек с малым количеством исходной ДНК. Сильнее всего это затрагивает клеточные фракции 0,22 мкм, Бирагзанг и отрицательный контроль (`results/qc/fastp/`).

## Структура

```
README.md
docs/pipeline.md            шаги, параметры, версии программ и баз, порядок запуска
metadata/                   библиотеки, точки отбора, md5 сырых прочтений
envs/                       окружения conda (yml и точные спецификации)
scripts/
  pipeline/                 конвейер 01–10: от сырых прочтений до каталога vOTU и таблиц покрытия
  analysis/                 анализ 00–14: чистота фракции, контаминант, профаги, хозяева, происхождение фагов
tests/check_reproducibility.sh   пересчёт и побайтная сверка результатов конвейера
results/
  qc/fastp/                 отчёты fastp
  filtering/                отбор вирусных кандидатов (шаг 5)
  checkv/                   CheckV по строгому набору кандидатов
  catalog/                  каталог vOTU (шаг 6)
  mapping/                  покрытие каталога в 11 библиотеках (шаг 8)
  references/               сравнение с бактериальными сборками тех же точек (шаг 10)
  genomad/                  geNomad: каталог и общий референс
  assembly_stats/           статистика сборок
  step6/                    картирование 11 библиотек на общий референс
  prophage/                 встроенные vOTU
  contamination/            MV-специфичная бактериальная ДНК: тест по прогону, 16S, рибосомные белки, идентичность
  hosts/                    CRISPR, PHIST, таксономия контигов-хозяев
  matrix/                   рарефицированная детекция
  tables/                   сводные таблицы анализа
```

### Какой файл отвечает на какой вопрос

| Вопрос | Файл |
|---|---|
| Какие фаги найдены, их таксономия и рекомендация по каждому | `results/tables/votu97_catalog_flags.tsv` |
| Связан ли фаг с MV-специфичной бактериальной ДНК | `results/tables/votu_origin.tsv` |
| Насколько фаги новые, гены лизогении | `results/tables/votu_novelty_lysogeny.tsv` |
| Покрытие каждой vOTU в каждой библиотеке | `results/mapping/votu97_all_libraries.tsv`, `results/tables/votu_coverage_matrix.tsv` |
| Подтверждение клеточной фракцией | `results/tables/votu_confirmed_cellular.tsv` |
| Доля MV-специфичной ДНК в библиотеках | `results/tables/votu_contaminant_ratio.tsv`, `results/contamination/runwide_presence.tsv` |
| Чистота фракции (16S, рибосомные белки) | `results/tables/purity_table.tsv` |

## Воспроизведение

1. Создать окружения из `envs/*.yml` (`conda env create -f …`).
2. Задать пути в `scripts/pipeline/config.sh`.
3. Запустить конвейер `scripts/pipeline/01_…` – `10_…` по порядку, затем анализ `scripts/analysis/00_…` – `14_…`.
4. Сверить результаты: `tests/check_reproducibility.sh`.

Подробности — `docs/pipeline.md`. Скрипты анализа используют абсолютные пути сервера labg, заданные переменными в начале каждого скрипта.
